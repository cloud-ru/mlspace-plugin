# MLSpace Plugin

Работайте с Cloud.ru MLSpace из **Claude Code, Codex или OpenCode**:
попросите агента найти задачу, разобраться в ошибке или подготовить перенос данных.

Плагин объединяет MCP-сервер и скиллы — инструкции для агента по типовым задачам.
Сервер запускается на вашем компьютере и обращается к API MLSpace с вашими правами.
Поддерживаются **macOS и Linux**, в том числе работа по SSH.

## Что можно делать

| Задача | Пример запроса агенту |
| --- | --- |
| Посмотреть обучение | «Покажи запущенные задачи в выбранных воркспейсах» |
| Разобраться в ошибке | «Почему упала эта задача? Посмотри логи» |
| Подготовить запуск | «Помоги запустить обучение: сначала уточни образ и ресурсы» |
| Работать с ноутбуками | «Покажи мои ноутбуки и их состояние» |
| Перенести данные | «Подготовь перенос датасета с S3 на NFS» |
| Проверить инференс | «Покажи состояние сервиса и помоги разобраться в ошибке» |

Также доступны Docker Registry, TensorBoard, аллокации и очереди.
Агенту можно писать обычным языком — имена MCP-инструментов запоминать не нужно.

## Быстрый старт

Нужны установленный клиент, **Git**, **uv** и два ключа Cloud.ru:
**Key ID** и **Key Secret**. Если чего-то ещё нет, начните с [инструкции установки](INSTALL.md).

Выполните в своём терминале:

```sh
uvx --python ">=3.10" \
  --from "git+https://github.com/cloud-ru/mlspace-plugin.git@main" \
  mlspace-plugin setup
```

1. Выберите, к каким клиентам подключить плагин.
2. Введите два ключа и выберите воркспейсы с помощью поиска.
3. Дождитесь окончания настройки и откройте новую сессию клиента.

MCP и скиллы подключаются вместе. Отдельно запускать сервер не требуется.
Первым сообщением попросите:

> Покажи выбранные воркспейсы и запущенные задачи, ничего не меняй.

Ключи вводятся только в терминале и сохраняются локально. Не отправляйте их агенту в чат.
По умолчанию доступны и чтение, и изменение ресурсов; если нужны только наблюдения,
включите [режим только для чтения](REFERENCE.md#режимы-работы-и-подтверждения).

## Обновление

```sh
uvx --refresh --python ">=3.10" \
  --from "git+https://github.com/cloud-ru/mlspace-plugin.git@main" \
  mlspace-plugin setup --force
```

Сохранённые ключи используются повторно. После обновления откройте новую сессию клиента.
Подробнее — в [инструкции по обновлению](INSTALL.md#обновление-и-повторная-настройка).
